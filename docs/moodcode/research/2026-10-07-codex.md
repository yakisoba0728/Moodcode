# Codex 공개 엔진 비교

2026-10-07에 [openai/codex](https://github.com/openai/codex)의 공개 소스를 별도 참고 디렉터리에 clone했다. 분석 commit은 `0b863c69f50335acd92164aab971cb58d298c2fe`다. checkout의 `LICENSE`는 Apache-2.0 고지다. Moodcode에 원본 코드·프롬프트·테스트를 복사하지 않았으며 upstream 실행·빌드도 하지 않았다.

## 확인한 경계

[local compaction](https://github.com/openai/codex/blob/0b863c69f50335acd92164aab971cb58d298c2fe/codex-rs/core/src/compact.rs)은 context overflow와 interruption/budget exhaustion을 구분하며, 요약 요청에서 오래된 history를 줄이는 경로와 사용자 원본 content parts를 보존하는 경로를 갖는다. [image compaction](https://github.com/openai/codex/blob/0b863c69f50335acd92164aab971cb58d298c2fe/codex-rs/core/src/compact_remote_v2_images.rs)은 image를 text와 다른 atomic 단위로 다룬다. 이는 이미지 reference의 작은 JSON 크기를 실제 image token 비용으로 취급하면 안 된다는 설계 근거다.

[context normalization](https://github.com/openai/codex/blob/0b863c69f50335acd92164aab971cb58d298c2fe/codex-rs/core/src/context_manager/normalize.rs)은 누락된 call output과 media modality를 별도 문제로 처리한다. Moodcode는 자체 journal의 실제 완료 결과를 기준으로 완전한 exchange만 모델에 보내며, 저장되지 않은 효과를 성공한 결과로 만들어 넣지 않는다.

[agent budget controller](https://github.com/openai/codex/blob/0b863c69f50335acd92164aab971cb58d298c2fe/codex-rs/core/src/agent/control/budget.rs)는 shared budget 관측과 reminder publication을 관리한다. Moodcode는 기존 부모의 잔여 turn/tool/output/time을 예약하고, 첫 `delegate_task`의 실행은 matching approval·격리 worktree·읽기 허용목록에 묶는다. 공개 source의 shared-budget 원리에서 얻은 독립 설계 선택이며 동등한 제품 기능을 주장하지 않는다.

[turn token telemetry](https://github.com/openai/codex/blob/0b863c69f50335acd92164aab971cb58d298c2fe/codex-rs/core/src/state/turn_token_usage.rs)는 실제 응답한 모델별 관측을 모은다. Moodcode의 새로운 `attempt_usage`는 응답 attempt별 최신 누적 snapshot을 영구 보존한다. 기존 v1 event sum과 구분하며, 관측 없음·billing 미확인은 null/coverage로 표시한다.

## 이번 변경의 한계

Moodcode의 image token estimator는 아직 없으며 텍스트 byte estimate와 image byte caps만 제공한다. 이미지가 포함된 source를 text-only 의미 요약으로 대체하지 않고 명시적으로 거부한다. 오래된 active-prefix의 의미 요약, 모델별 image budget 추정, child 장기 재개 정책은 별도 구현·검증 항목이다. 최신 runtime 통과 범위는 루트 TODO와 해당 headless 검증 보고서가 결정한다.
