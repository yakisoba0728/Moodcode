## 3. 서버별 SDK와 V1/V2 호환 계층

ServerConnection은 http, sidecar(base/wsl), ssh union이다. key는 HTTP URL, sidecar, wsl:distro, ssh:host이며 local canonical backend의 UI persistence scope는 local로 통일한다. local과 remote의 같은 directory·session ID를 구분하는 ScopedKey/SessionStateKey는 null-byte separator를 사용하고 null-byte 입력을 거부한다. 이 scope는 탭·터미널·권한·파일 view·query key에 반복해서 사용된다. SSH는 HTTP proxy를 노출한다는 타입·key 정의가 있지만 app/desktop 범위에서 연결을 생성하거나 SSH 프로세스를 실행하는 경로는 찾지 못했다. 완성된 SSH 기능으로 집계하지 않는다. HTTP URL/credential은 저장 상태에 들어갈 수 있으므로 이것을 비밀 vault로 해석해서는 안 된다. ### 조사 범위와 제외 처리

git ls-files 기준 지정된 여섯 package의 추적 파일은 총 **2,826개**다: app 643, desktop 306, session-ui 118, ui 1,695, enterprise 36, storybook 28. 파일 목록은 모두 inventory했지만 모든 파일의 모든 줄을 읽었다는 뜻은 아니다. 주요 진입점·state/transport/provider·핵심 pure helper를 따라 읽었고 큰 component·테스트·story는 관련 함수와 대표 시나리오를 표본 조사했다.

범위 전체 SVG 1,215개와 i18n TypeScript 190개는 생성·타입·bridge·대표 consumer를 우선했다. assets의 폰트/오디오/image, 번역 문장 전체, theme 색상 값 전수, story별 시각 품질, debug/scrap 자료, build 산출물 내용 전수는 제외했다. 실제 vendored client tar는 제외하지 않고 manifest/Promise SSE 구현을 읽었으며, 자동 생성 SDK는 호출·인증·transport 계약에 필요한 부분만 표본 확인했다. 범위 밖 core/spec/sdk는 클라이언트가 소비하는 계약을 대조하기 위해 좁게 읽었고 내부 엔진/SQL/API 전체 분석은 주 담당에게 남겼다.

정확한 reviewed_paths, sampled_paths, 제외 이유, 실행 검증과 미확인 항목은 함께 저장한 **07-clients.coverage.json**에 기록했다. 원본 소스·lockfile·의존성·브랜치는 수정하지 않았다.
